# Grippy Box - Google Keep Clone

A simple, lightweight Google Keep clone built with HTML, CSS, and Vanilla JavaScript.

## Features

- **Add Notes:** Quickly capture your thoughts.
- **Edit Notes:** Update your notes anytime.
- **Delete Notes:** Remove notes you no longer need.
- **Pin Notes:** Keep important notes at the top.
- **Color Coding:** Categorize notes with different background colors.
- **Search:** Find notes easily with the search bar.
- **Persistence:** Your notes are saved locally in your browser using `LocalStorage`.

## Tech Stack

- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (Vanilla JS)
- Font Awesome (for icons)

## Deployment

### GitHub Pages
This project is set up to be deployed via GitHub Pages.

### Vercel
You can also deploy this project to Vercel with zero configuration.

## Local Development

Simply open `index.html` in your favorite web browser.

## Database Persistence
The application uses the browser's `LocalStorage` API to persist notes across sessions. This means your notes will stay even if you refresh the page or close the browser, as long as you don't clear your browser data.
